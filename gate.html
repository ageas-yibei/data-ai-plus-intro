When a person has to look什么时候需要人看

After the machine sorts a treaty’s files, it gets a colour. The colour is the only thing that decides how much attention that treaty needs. Green ships. Amber names a short list. Red sends the whole pack back. 机器把一份合约的文件分拣完后，会标出一种颜色。颜色决定这份合约需要人查看多少。绿灯放行。黄灯给出一份短名单。红灯把整份材料包退回给人。

Green绿灯

The sort looks sound. Nobody has to open this pack.分拣看起来靠得住。不必打开这份材料包。

Amber黄灯

The pack can go forward, but named files need a look.材料包可以往下走，但名单上的文件需要人过目。

A person works the list the gate wrote — not the whole treaty.人只处理关卡列出的名单，不是整份合约。

Red红灯

We do not trust the sort. The treaty goes back to a person.不信任这次分拣。整份合约退回给人。

The amber list still comes with it, so the person knows where to start.黄灯名单一并带上，方便人知道从哪里入手。

How the colour is picked颜色怎么定

  1. If any stop-the-pack test failed → red.任何一个“整份材料包停下”的测试未通过 → 红灯。
  2. Otherwise, if any look-at-these test failed → amber.否则，任何一个“复查这些文件”的测试未通过 → 黄灯。
  3. Otherwise → green.否则 → 绿灯。

Doubt only makes the colour worse. Keeping an extra file does not turn the light red — that file is still in the pack, and someone can read it. Throwing a file away on a weak reason does, because nobody will see it unless we say so. 存疑只会让颜色变得更差。多留一份文件不会变红——文件还在材料包里，有人能读到。凭弱理由扔掉文件才会，因为不点出来就没人会看见。

The pack can still go forward. A person works a named list — or, for two of these, just knows the treaty is an odd shape.材料包仍可以往下走。人按一份名单处理——其中两条只是说明这份合约的形态特殊。

It threw a file away on a weak reason凭弱理由扔掉了文件
A file in a submission folder was dropped, and the filename itself does not carry the reason. Check it before it leaves.提交文件夹里的文件被丢弃，而文件名本身不足以支撑这个理由。文件离开前要看一眼。
named files名单上的文件
Rule规则
G5_contested_discard
Which discards哪些丢弃要看
Only unique files in a recognised submission folder. Always contested: version-pair / UW-derivative name shapes. Contested unless the name itself fired: internal-signal, withdrawn-marker (body-only hits). Envelope mail, comparison tags, newsletters, OS junk, notes-folder, internal attachments and broker variants are never contested.仅限可识别的提交文件夹中的唯一文件。一律要看：版本对、核保衍生件这两类文件名形态。内部信号、撤回标记两条，仅命中正文时要看，文件名本身命中则不看。信封邮件、对比标记、通讯、系统垃圾、notes 文件夹、内部附件及经纪人变体，一律不看。
Unknown reason未知理由
A discard citing a reason the gate has never seen halts the build. It does not fail open.若丢弃理由是关卡从未见过的，构建直接停止，不会悄悄放过。

This is the file-sort gate这是文件分拣这一关

Facts extraction uses the same three colours later: green auto-accepts, amber checks flagged fields, red reviews the whole record, and retrospective cases are also checked against TPR booked values. That is a separate process, not this gate.后续的信息提取环节同样使用红黄绿三色：绿灯自动通过，黄灯核对被标出的字段，红灯复核整单；回溯案例还要与 TPR 入账值核对。那是另一套流程，不是这一关。
