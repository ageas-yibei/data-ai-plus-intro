When a person has to look什么时候需要人看

After the machine sorts a submission, a colour says whether the result can go downstream as it is. 机器分拣完一份提交，用红黄绿告诉你：这份结果能不能直接交给下游。

Green绿灯

It can go downstream as it is.可以直接交给下游。

A standing audit still sends about one green submission in five to a person.绿灯提交约每五份固定抽查一份，照样有人读。

Amber黄灯

Double check needed: someone looks before it goes on.需要复核：有人看过，再往下送。

Most amber rules name the files to check: look at those, not the whole treaty.多数黄灯规则会列出要看的文件：看这些就行，不必看整份合约。

Red红灯

Investigation needed: find out why before it goes on.需要查清：先查明原因，再往下送。

Any files the amber rules name are listed too: start there.黄灯规则点名的文件也一并列出，可以从那里入手。

How the colour is picked颜色怎么定

  1. If the treaty is parked or not sorted yet → red, until it is unparked or sorted.合约被搁置或还没分拣 → 红灯，直到解除搁置或分拣完。
  2. Otherwise, if any investigation-needed rule fired → red.否则，“需要查清”的规则只要有一条触发 → 红灯。
  3. Otherwise, if any look-at-these-files rule fired → amber.否则，“复查这些文件”的规则只要有一条触发 → 黄灯。
  4. Otherwise → green.否则 → 绿灯。

Keeping an extra file never makes the colour worse; throwing one away can. 多留一份文件，颜色不会变差；扔掉一份，却可能变差。

When somebody has already looked已经有人看过之后

Answers and confirmations count only in the round they were given in.答复和确认只在给出的那一轮算数。

What a review changes复核会改变什么

  1. A settled file comes off every list that names it.定下来的文件，从点名它的每份名单上划掉。
  2. Confirming the submission clears the rules about it as a whole.确认这份提交，针对整份提交的规则即消除。
  3. Once every listed file is settled and the submission is confirmed, it turns green.名单上的文件都定下来、提交也确认后，即转为绿灯。
  4. When the pack is built again, a settled file a person kept goes in, and one a person dropped comes out.材料包重新生成时，已定下来的文件，人留下的进包，人扔掉的出包。

A review never leaves the colour worse than the machine’s alone. 复核不会让颜色比机器单独判定的差。

What counts as a review什么才算复核

  1. A person’s answer settles a file, unless the file is flagged, or two reviewers answered it opposite ways and the approver has not ruled.有人答复过的文件即定下来；标了疑问的除外，两个复核人答复相反、批准人又没裁定的也除外。
  2. Confirming the submission settles every file nobody answered, except a flagged one.确认这份提交，没人答复的文件一并定下来，标了疑问的除外。
  3. A confirmation counts from the approver where one is named, otherwise from an assigned reviewer; for a submission the assignment list leaves out, only if nobody else recorded anything.指定了批准人的，只认批准人的确认；没指定的，认分派到的复核人的。分派名单上没有这份提交的，别人都没留过记录，确认才算数。
  4. A review outside the review app (the only kind for MVP20 and MVP3) counts only as a row of the sign-off register, which settles every file as the machine called it and clears the rules about the submission as a whole.复核工具之外的复核（MVP20 与 MVP3 只能这样）只认签核登记表：登记了的合约，每份文件按机器的结论定下来，针对整份提交的规则也一并消除。

If a new sort changes the files or any of the machine’s calls, the confirmation lapses until someone confirms again; answers on unchanged files still hold. 重新分拣后，只要文件有变，或机器对哪份文件的结论有变，原先的确认就失效，要有人再确认一次；文件没变的，答复照旧有效。

This is the file-sort gate这是文件分拣这一关
