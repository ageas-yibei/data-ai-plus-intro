A script fetches the files from EFS; each submission is identified by TNO and underwriting year. Nothing is filtered. Yibei triggers the script at MVP; automatic through Jinchao's API at production. No sign-off.脚本从 EFS 拉取文件；每份申请以 TNO 和承保年度标识。不做筛选。MVP 阶段由 Yibei 触发脚本，上线后通过 Jinchao 的 API 自动完成。无需签核。

YibeiSubmission Agent
Yibei triggers the Submission Agent. A deterministic rule picks the Core files; the LLM only classifies what the rule can't. Every file is kept, tagged Core or Others. Signed off at step 3.Yibei 触发 Submission Agent。确定性规则先选出核心文件，规则未命中的才交给 LLM 分类。所有文件都保留，标记为核心或其他。在第 3 步签核。

B Facts Agent
4

Data extraction数据提取

HenriFacts Agent
Henri triggers the Facts Agent. It reads the validated Core files into one TreatyRecord: every field on the signed Shopping List, with where each value was found. Locates, never invents. If no recipe fits this treaty, Aidon writes one (with a coding agent) and the run repeats. Signed off at step 5.Henri 触发 Facts Agent。它将已确认的核心文件读取为一条 TreatyRecord：按已签核的 Shopping List 逐字段提取并记录出处。只定位，不臆造。若没有适用的 recipe，由 Aidon（借助编码 agent）编写后重跑。在第 5 步签核。
Waiting for validated Core等待已确认核心 Record extracted记录已提取 No recipe fits无适用 recipe → BA writes oneBA 编写 Fields missing字段缺失 → Henri (e.g. image tables)
5

Result validation结果验证

Reviewer复核人→Andrew / Susana
Validation Flywheel, Module B. The vendor reviewer checks the record field by field; the Domain Specialist signs it off and rules on any field that differs from what TPR booked. Answer key = TPR booked values, retrospective cases only. Corrections go back to Henri.验证飞轮，模块 B。外包复核人逐字段检查记录；领域专家签核，并裁定与 TPR 入账值不一致的字段。标准答案 = TPR 入账值，仅回溯案例。纠正结果反馈给 Henri。
