How each file is sorted每份文件怎么分拣

The rules sort each file into CORE or something else. Where a person has reviewed a file, the review decides. 规则把每份文件分成 CORE 或其他。有人复核过的，以复核为准。

At a glance一览

Checked from the top; the first step that matches decides. The two + rows come last, for every file.从上往下查，先命中哪一步就按哪一步定。标 + 的两行最后查，每份文件都要过。

What the rules read规则读什么

Most decisions rest on the file name, and so do most mistakes.多数判断靠文件名，多数错判也出在文件名上。

Folder文件夹

Which folder the file is in, such as a submission or notes folder.文件在哪个文件夹，比如提交文件夹、备注文件夹。

Limit:局限： a file saved in the wrong folder can get the wrong answer.文件放错了文件夹，就可能判错。

File name文件名

Limit:局限： a name that says nothing, or the wrong thing, can give the wrong answer.文件名什么都没说或说错了，就可能判错。

Format格式

The extension, such as .pdf or .xlsx.扩展名，如 .pdf、.xlsx。

Limit:局限： the extension does not say what is inside: a PDF can be a slip, a printed email or a photo.扩展名说明不了里面是什么：同为 PDF，可能是条款单、打印的邮件或照片。

Content内容

The text the machine extracted. For a file it extracted none of, such as a scan, the words the vision model read off its pages.机器读出的文字。一个字都没读出的文件，比如扫描件，读视觉模型从页面上转写出的文字。

Limit:局限： a file with neither has nothing to read. A PDF with text of its own is read by that text alone, not by the vision model's reading of its scanned pages. A reading made after the rules ran counts only once they run again.两样都没有的文件，无字可读。本身读得出文字的 PDF，只读这些文字，不读视觉模型对其中扫描页的转写。规则跑过之后才做的转写，要等规则重跑才算数。

Other files in the same treaty同一合约的其他文件

Some steps need the treaty's other files, such as whether another document lists this one as sent, or whether it is an exact copy.有些步骤要看本合约的其他文件，比如有没有别的文件列明送了这份，或它是不是另一份文件完全相同的副本。

How the type is worked out类型怎么定

First the name; where it says too little, the title at the top of the document (a scan's, off the vision model's reading) or a workbook's sheet names; then the words of the name and of a workbook's cells that the table gives for the type alone, which no rule reads; then the folder; then the format.先看文件名；文件名说得不够，再看文件开头的标题（扫描件看视觉模型转写出的标题）或工作簿的工作表名；然后看表中“只用于定类型”的文件名用词和工作簿单元格，这些规则都不读；然后看文件夹，再看格式。

A workbook's cells are the first 80 pieces of text in an .xlsx or .xlsm, or an .xls that is really one: the type is the part of the submission at least two of them name, and more than name any other. Where a workbook's name names two parts, such as losses and statistics, its cells choose between those two the same way; a name of one part keeps it. A file in a post-binding folder is read for the type alone only if it, or an exact copy, is in Slip & End't or U W Information.工作簿单元格，指 .xlsx、.xlsm（或实为这两种的 .xls）里的前 80 段文字：至少两段指向同一类提交材料、且多于指向其他任何一类的，就定为这一类。工作簿文件名同时点了两类提交材料的，比如赔付和统计，也这样按单元格在两类里选；文件名只点了一类的，就按这一类。成交后文件夹里的文件，只有本身或其完全相同的副本在 Slip & End't 或 U W Information 里，才看“只用于定类型”的词。

A notes, post-binding or Reciprocal Business folder overrides the type: the file becomes ours, post-binding or reciprocal business. Emails, Q&A, line confirmations, comparisons, archives, images and system files keep their own type, and so does a file that is, or has an exact copy, in Slip & End't or U W Information.备注、成交后或 Reciprocal Business 文件夹会改掉文件原有的类型，分别改为我方、成交后或互惠业务。邮件、问答、份额确认、对比、压缩包、图片、系统自动生成的文件不改；本身或其完全相同的副本在 Slip & End't、U W Information 里的也不改。

The other three columns另外三栏

Signed: yes if the name says S+R, signed, countersigned, signiert or executed.是否签署：文件名写着 S+R、signed、countersigned、signiert 或 executed 的，记 yes。

Version: draft, redline or final, if the name says which.版本：文件名写明 draft、redline 或 final 的，照记。

Basis: whether the type came from the name, the text, the folder or the format.依据：类型是按文件名、正文、文件夹还是格式定的。

What these rules do not decide这些规则不管的事

Whether the whole submission can go on without a person checking it is for the RAG Gate.整份提交能不能不经人看就往下送，由 RAG 闸门判断。

Nothing after the rules changes an answer. A person's Keep or Drop changes what goes on to the Facts Agent, not the answer.规则定下的结论，后面的环节都不改。人标的 Keep 或 Drop，改的是交给数据提取智能体的文件，不改结论。
