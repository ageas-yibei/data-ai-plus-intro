How each file is sorted每份文件怎么分拣

Every file in a submission gets one of six answers, and only CORE goes downstream. One ladder of rules gives the answer: the first step that fires decides, a file no step claims goes to a person, and nothing is deleted. 提交里的每份文件，都得到六种结论之一，只有 CORE 往下游送。结论由一条规则阶梯给出：首条命中的规则即为结论；没有规则认领的文件交给人；任何文件都不删除。

The four things it can read能读的只有四样

The name does most of the deciding, and causes most of the mistakes.判断多半落在文件名上，错判也多半出在这里。

Folder位置

Where the file sits in the export: a submission folder, a notes folder, an approvals folder.文件在导出目录中的位置：提交材料、备注、审批。

Blind to:看不见： a document filed in the wrong place. A folder can keep a file out, and only the two submission folders can let one in — under a reason that says so.放错位置的文件。文件夹能挡；只有两个提交文件夹能放行，且结论会写明是文件夹放行的。

File name文件名

The filename text, and for most rules the only thing they read. Read as its author wrote it: the export's id prefix is not part of the name, and a name the export split at a “/” is put back together first.文件名本身，也是多数规则唯一读的东西。读的是作者起的名字：导出系统加的编号前缀不算名字，被导出系统在“/”处拆成两级的名字先拼回去。

Blind to:看不见： a name that says nothing, or says the wrong thing. Every known miss started here.什么都没说、或说错了的名字。已知漏判都始于此。

File type格式

The extension. This one is never misread.扩展名。这一样不会看错。

Blind to:看不见： what is inside. A PDF is a slip, a printed email or a photograph, and the extension cannot say which.文件里究竟是什么。同为 PDF，可能是条款单，可能是打印的邮件，也可能只是一张照片。

Content内容

The text the machine extracted. Three tests read only the first 500 to 800 characters: the withdrawal words, the email headers, the internal words. The kind of document, the market reference and the cedant's list of what it sent are looked for past the opening too.机器读出的文字。作废用语、邮件头、内部用语这三项，只看开头 500 至 800 字符；文件类别、市场编号、分出公司的送件清单，开头之后也找。

Blind to:看不见： a scan. The vision model's transcription of a scan reaches the pack and the review app, never these rules.扫描件。视觉模型对扫描件的转写进材料包、进复核工具，不进这些规则。

And a fifth: the rest of the treaty还有第五样：同一份合约里的其他文件

Questions a single file cannot answer: did another document list it as sent, is it one of a numbered appendix series, which market reference is this treaty's, is a cleaner copy already kept, were these bytes seen before, are the submission folders in use, does a copy of it sit in one.有些问题单看一份文件答不上来：别的文件是否列明送了它、附件是否成套编号、哪个市场编号是本合约的、是否已留下更干净的一版、这批字节此前是否见过、提交文件夹是否在用、是否有一份副本放在里面。

Read in this order按这个顺序读

The name. Where the name says nothing, or only half, the text: the title at the top of the document, a workbook's sheet names. Then the folder: Slip & End't is the contract, U W Information the submission. Then the format: a workbook nothing else typed is premium and statistics. An email by its subject, never its body.先看文件名。文件名什么都没说、或只说了一半，再看正文：文件开头的标题、工作簿的工作表名。再看文件夹：Slip & End't 是合约，U W Information 是提交材料。最后看格式：别处都定不了类型的工作簿，算保费与统计。邮件只看主题，不看正文。

The folder also says whose and when: in a notes folder a slip is our working copy, and in Loss information, Results, Special Acceptances or PNC a file came after binding.文件夹还说明是谁的、何时来的：备注文件夹里的条款单，是我方的工作副本；Loss information、Results、Special Acceptances、PNC 里的文件，是成交之后来的。

Not on this page不在这一页的事

These rules decide what each file is. Whether the submission can go downstream without a person is a separate judgement, made afterwards on the result as a whole — that is the RAG Gate.这些规则决定每份文件是什么。整份提交能否不经人工直接往下走，是此后就整体结果另作的判断，即 RAG 闸门。

A mistake is never quietly corrected downstream; it surfaces as a disagreement in the review app. And the count of documents it is known to miss is a floor, not a measurement: the selections it was scored against were themselves made starting from its output.出错不会在下游被悄悄改掉，只会作为“分歧”出现在复核工具里。已知漏判数是下限，不是测量值：用来对照的人工选取，本身就是从机器的输出出发做的。
