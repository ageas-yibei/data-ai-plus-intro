What the machine reads机器读什么

Every file goes down one ladder, and the first step that fires decides it. A step reads some of four things: the folder, the file name, the file type, the content. Most read the name and nothing else. 每份文件都走同一条阶梯，首条命中的规则即为结论。每一步只读四样东西中的几样：位置、文件名、格式、内容——多数规则只读文件名。

The four things it can read能读的只有四样

The name does most of the deciding, and causes most of the mistakes.判断多半落在文件名上，错判也多半出在这里。

Folder位置

Where the file sits in the export: a submission folder, a notes folder, an approvals folder.文件在导出目录中的位置：提交材料、备注、审批。

Blind to:看不见： a document filed in the wrong place. A folder can keep a file out; it can never let one in.放错位置的文件。文件夹只能挡，不能放行。

File name文件名

The filename text, and for most rules the only thing they read.文件名本身，也是多数规则唯一读的东西。

Blind to:看不见： a name that says nothing, or says the wrong thing. Every known miss started here.什么都没说、或说错了的名字。已知漏判都始于此。

File type格式

The extension. This one is never misread.扩展名。这一样不会看错。

Blind to:看不见： what is inside. A PDF is a slip, a printed email or a photograph, and the extension cannot say which.文件里究竟是什么。同为 PDF，可能是条款单，可能是打印的邮件，也可能只是一张照片。

Content内容

The text the machine extracted. Most rules see only the first 500 to 800 characters of it.机器读出的文字。多数规则只看开头 500 至 800 字符。

Blind to:看不见： a scan, until the vision model has read it — and anything past the opening.扫描件（除非视觉模型已读过），以及开头之后的一切。

And a fifth: the rest of the treaty还有第五样：同一份合约里的其他文件

Four questions a single file cannot answer: is there a numbered appendix series, is a cleaner copy already kept, were these bytes seen before, are the submission folders in use.有四个问题单看一份文件答不上来：附件是否成套编号、是否已留下更干净的一版、这批字节此前是否见过、提交文件夹是否在用。

What happens to it后续
It goes on the review queue. The gate turns the treaty amber for it, and red when the machine took no position on more than half the pack — today the only reason a treaty is not trusted.进入复核队列。闸门因此标黄；机器若对过半文件都没有表态，则标红——目前唯一会让一份合约失去信任的理由。
It can still carry a finding“不知道”也可能带着提示
A file carrying another treaty's market reference is left undecided and carries that finding, so the reviewer sees why it is on the queue.带着别份合约市场编号的文件留在“不知道”，但带上那条提示，复核的人一眼便知它为何在队列里。

Two passes after the ladder阶梯之后的两轮

Both read only a file's standing, never why it has it.这两轮只认当前结论，不问由来。

A cleaner copy is already kept已留下更干净的一版

A CORE file with _broker in its name drops to SECONDARY when a non-broker CORE sibling exists. Because it reads only the standing, it can override even a cedant declaration.名字带 _broker 的 CORE 文件，若已有非经纪人版本同为 CORE，则降为 SECONDARY。因只认当前结论，连分出公司的声明也能覆盖。

The same bytes as another file与另一份文件字节相同

No rule is run on a byte-identical copy. It is inventoried so it stays visible, then takes its twin's answer at the end — so the same bytes never come out CORE in one folder and SECONDARY in another. Its reason reads inherited_from_representative.字节相同的副本不参与任何规则判定，但照样进清单以保持可见，最后照抄同源文件的结论。同一批字节，不会在一处是 CORE、在另一处是 SECONDARY。理由写作 inherited_from_representative。

A last step follows the chain of copies to the original, so opening a duplicate always leads to the real document.最后一步顺副本链上溯到原件，点开副本总能落到真正的文件上。

Four guarantees四条底线

Four things that hold whatever the file is.无论文件是什么，这四条都成立。

Nothing is ever deleted任何文件都不会被删除

Every demotion lands on a visible answer. A file set aside is still in the inventory, with the rule and the quoted evidence beside it.每次降级都落在一个看得见的结论上。搁置的文件仍在清单里，旁边写明规则与引用的证据。

Out of scope means undecided, not dropped超出范围等于“不知道”，不等于丢弃

The folder condition refuses to grant CORE; it never takes a file off the ladder. A cedant document misfiled into a notes folder surfaces for a person.文件夹条件只是拒绝授予 CORE，从不把文件逐出阶梯。错放进备注文件夹的分出公司文件，仍会浮出来交给人。

An unfamiliar folder layout costs a treaty nothing归档方式不同，不连累整份合约

A treaty using neither submission folder files its papers another way, so the condition does not apply. Without this, one unfamiliar layout would strip CORE from that treaty at once.两个提交文件夹都不用的合约，另有归档习惯，条件不生效。否则一种没见过的目录结构，便会一次剥掉这份合约的全部 CORE。

No folder ever grants CORE文件夹永远不能授予 CORE

A folder can keep a file out at step 6 and push it to internal at step 7. It can never let one in. A core-looking document filed under notes is flagged as possibly misfiled, not reclassified.文件夹能在第 6 步挡住文件，也能在第 7 步把它推成 INTERNAL，却永远不能放行。看着像核心、却放在备注文件夹的文档，只标“可能放错位置”，不予改判。

Not on this page不在这一页的事

These rules decide what each file is. Whether the treaty can go downstream without a person is a separate judgement, made afterwards on the result as a whole — that is the RAG Gate.这些规则决定每份文件是什么。整份合约能否不经人工直接往下走，是此后就整体结果另作的判断，即 RAG 闸门。

A mistake is never quietly corrected downstream; it surfaces as a disagreement in the review app. And the count of documents it is known to miss is a floor, not a measurement: the selections it was scored against were themselves made starting from its output.出错不会在下游被悄悄改掉，只会作为“分歧”出现在复核工具里。已知漏判数是下限，不是测量值：用来对照的人工选取，本身就是从机器的输出出发做的。
