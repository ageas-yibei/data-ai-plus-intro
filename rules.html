How each file is sorted每份文件怎么分拣

Every file in a submission gets one of six answers. Only CORE files go on to the Facts Agent, which extracts the data. The steps are checked in order, and the first one that matches decides. If none matches, a person decides. No file is ever deleted. 提交里的每份文件都会得到六种结论之一。只有 CORE 文件交给数据提取智能体（Facts Agent）提取数据。规则按顺序逐步检查，第一步命中就定结论；一步都没命中，交给人判断。任何文件都不删除。

What the rules read规则读什么

Most decisions rest on the file name, and so do most mistakes.多数判断靠文件名，多数错判也出在文件名上。

Folder文件夹

Which folder of the export the file is in: a submission folder, a notes folder, an approvals folder.文件在导出目录的哪个文件夹里：提交材料、备注、审批。

Limit:局限： a file saved in the wrong folder can get the wrong answer. The folder alone makes a file CORE only in the two submission folders, and the reason then says so: core_in_submission_folder.文件放错了文件夹，就可能判错。单凭文件夹定 CORE，只限两个提交文件夹，理由会写明 core_in_submission_folder。

File name文件名

Most rules read only this. The ID prefix the export adds is removed first, and a name the export split at a “/” is joined back.多数规则只读文件名。先去掉导出系统加的编号前缀；名字含“/”、被导出系统拆成两级的，先拼回原名。

Limit:局限： if the name says nothing, or says the wrong thing, the answer can be wrong. Every known miss began with the name.文件名什么都没说或说错了，就可能判错。已知漏判都是从文件名开始的。

Format格式

The extension. Never misread.扩展名。不会看错。

Limit:局限： the extension does not say what is inside. A PDF can be a slip, a printed email or a photo.扩展名说明不了文件里是什么。同为 PDF，可能是条款单、打印的邮件，也可能只是一张照片。

Content内容

The text the machine extracted. Some tests read only the start: the withdrawal words, the email headers and the internal words in the first 500 to 800 characters; the title that gives the type in the first 500, or a workbook's sheet names. An email is read in its subject and its newest message, or all of it for a forward or a whole thread. The market reference and the cedant's list of what it sent are searched in the whole text.机器读出的文字。有几项只看开头：作废用语、邮件头、内部用语看前 500 至 800 个字符；定类型的标题看前 500 个字符，或工作簿的工作表名。邮件看主题和最新一封；转发或整串打印的邮件看全文。市场编号和分出公司的送件列表，全文都找。

Limit:局限： a scan has no text for the rules to read. The vision model's transcription of a scan goes to the Facts Agent and the review app, but no rule reads it.扫描件没有文字可读。视觉模型转写的文字会交给数据提取智能体，也进复核工具，但规则不读。

Other files in the same treaty同一合约的其他文件

Some questions need the other files: did another document list it as sent, is it part of a numbered APP series, which market reference is this treaty's, is the same file without _broker CORE, is it an exact copy of another file, are the submission folders in use, is a copy of it in one.有些问题要看别的文件才答得出：别的文件有没有列明送了它、它是否属于成套编号附件、哪个市场编号是本合约的、不带 _broker 的同一文件是否是 CORE、它是不是别的文件的完全副本、合约是否用了提交文件夹、有没有副本放在提交文件夹里。

How the type is worked out类型怎么定

First the name. If the name says nothing or too little, the text: the title at the top of the document, or a workbook's sheet names. Then the folder: Slip & End't means contract, U W Information means submission. Last the format: a workbook nothing else typed is premium and statistics. An email is typed by its subject, never its body. Step 6 uses only the name and the text.先看文件名。文件名没说或说得不够，再看正文：文件开头的标题，或工作簿的工作表名。再看文件夹：Slip & End't 是合约，U W Information 是提交材料。最后看格式：别处都定不了的工作簿，算保费与统计。邮件只看主题，不看正文。第 6 步只用文件名和正文。

The folder also says whose and when: in a notes folder a slip is our working copy, and a file in Loss information, Results, Special Acceptances or PNC came after binding.文件夹还说明是谁的、什么时候来的：备注文件夹里的条款单是我方工作副本；Loss information、Results、Special Acceptances、PNC 里的文件是成交之后来的。

The other three columns另外三栏

uw_signed: yes if the name says S+R, signed, countersigned, signiert or executed.：文件名写着 S+R、signed、countersigned、signiert 或 executed，记 yes。

uw_version: draft, redline or final, if the name says which.：文件名写明 draft、redline 或 final 的，照记。

uw_basis: what gave the type: the name, the text, the folder or the format.：类型从哪来：文件名、正文、文件夹或格式。

What these rules do not decide这些规则不管的事

These rules decide what each file is. Whether the whole submission can go on without a person checking it is decided afterwards, by the RAG Gate.这些规则只判断每份文件是什么。整份提交能不能不经人看就往下送，之后由 RAG 闸门判断。

A wrong answer is never fixed silently downstream; it shows up in the review app as a disagreement. The known number of misses is a minimum, not a measurement: the people who checked the answers started from the machine's output.错判不会在下游被悄悄改掉，只会在复核工具里显示为“分歧”。已知漏判数只是下限，不是实测：人工核对本身就是从机器的结果出发的。
