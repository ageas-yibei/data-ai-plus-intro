How a figure is counted数字怎么算

  • Identical copies of a file in one submission count once.同一份提交里完全相同的文件只算一份。
  • The rules’ CORE counts as kept; SECONDARY, INTERNAL, DERIVED and WITHDRAWN as dropped; UNDECIDED as no answer.规则的 CORE 算留下；SECONDARY、INTERNAL、DERIVED、WITHDRAWN 算不留；UNDECIDED 算没下结论。
  • MVP20 and TEST15 were answered on the machine’s output, so their recall cannot count a document the machine never listed.MVP20、TEST15 是对着机器的分拣结果作答的，机器没列出的文件，召回率算不到。
  • MVP20’s answers include the project owner’s 34 corrections: an email naming the written or signed line is core.MVP20 的答案含项目负责人的 34 处更正：写明承保份额的邮件算核心。
  • Where the TEST15 reviewer changed nothing, v5’s answer stands, and v5’s undecided counts as dropped.TEST15 复核人没改的，沿用 v5 的结论；v5 没下结论的算不留。
  • Of the 74 answers the TEST15 reviewer changed, d09e319 matches 11, b9140d4 19, and 7e6db6b and every version since 20.TEST15 复核人改过的 74 条里，和复核人一致的：d09e319 11 条，b9140d4 19 条，7e6db6b 及之后各版 20 条。
